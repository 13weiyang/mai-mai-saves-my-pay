# Agent 对话示例

> 展示这个 Skill 在真实对话里怎么用。**每条都照着 `skill/mai-mai-saves-my-pay/SKILL.md` 的流程走。**
>
> ⚠️ **下文金额为流程示意，不是真实订单数据**；实际一律以官方 `calculate-price` 返回为准。

---

## 示例 1 · 最基础：说一句，它就点

**用户**：来份巨无霸，再来个冰美式中杯。

**Agent**：
**先定门店** —— 你没说哪家，我按「北京 · 嘉秀」找了最近的 3 家：

| 门店 | 距离 |
|---|---|
| 麦当劳北京嘉秀路餐厅 | 15 米 |
| 麦当劳北京建外SOHO(A座)餐厅 | 8.4 公里 |
| 麦当劳北京善缘街(中关村5号)餐厅 | 18.4 公里 |

用最近这家（嘉秀路），对吗？

（用户确认后）拉菜单 → 匹配 → **先把能领的券替你全领了** → 官方算价：

| | |
|---|---|
| 原价合计 | ¥38.50 |
| 门店现价折扣 | −¥3.00 |
| 券 | −¥2.00 |
| **实付** | **¥33.50** |

要下单吗？

> **⚠️ 关键**：
> - 用户说「冰美式中杯」，菜单里叫「**麦咖啡™美式**」—— 去掉规格词才匹配得上。
> - 报的是**实付**，不是原价。
> - 券是**替他领的**，不是提醒他去领。

## 示例 2 · 不知道吃啥：先看菜单

**用户**：想吃麦当劳，但不知道点啥。

**Agent**：先把这家店有什么摊给你看（带官方产品图）——

```
【汉堡】12 款
   巨无霸  ¥24.50
   https://menu-img.mcd.cn/...
【套餐】18 款
   ……
```

看中哪个，说一声就点。

> **⚠️ 关键**：**有图才有食欲。** 不知道吃啥时别硬猜，先看菜单。

## 示例 3 · 套餐自选：「我要自己挑那 7 件」

**用户**：堡堡随心拼那个，7 件我想自己挑。

**Agent**：打开选择面板 ——

```
第1轮 主食任意选        已选 2/2
   麦辣鸡腿汉堡 / 板烧鸡腿堡 / 巨无霸 / 双层吉士汉堡
第2轮 选择随心配小食    已选 3/3
   麦辣鸡翅2块 / 麦乐鸡5块 / 麦麦脆汁鸡-琵琶腿 / 奥利奥麦旋风 / 中薯条
第3轮 选择套餐内饮料    已选 2/2
   可乐中杯 / 雪碧中杯 / 阳光柠檬红茶中杯 / 黄金橙橙 / 锡兰红茶
```

> **⚠️ 关键**：
> - 默认是**官方默认搭配**，不是 Agent 瞎猜的
> - **每轮必须选够件数**（官方规则是"正好选 N 件"）
> - **换贵的选项，价格当场涨**
> - **只有真拿得到数据的款才给这个入口** —— 没数据的不装、不编

## 示例 4 · 下单（最重要的一段）

**用户**：就这个，下单。

**Agent**：**先把这一单原样复述一遍，你确认了才动** ——

```
门店：麦当劳北京嘉秀路餐厅（1950751）
      北京市朝阳区…… · 约 15 米
取餐：堂食 · 店内用餐
清单：
  巨无霸                ×1   ¥24.50
  麦咖啡™美式           ×1   ¥14.00
原价合计：¥38.50
官方实付：¥33.50
```

**确认下单吗？**

（用户回"确认"后）

**Agent**：下好了。**这是麦当劳官方的支付链接** → [链接]

支付在麦当劳官方渠道完成，**我们不经手钱**。

> **⚠️ 三条红线**：
> 1. **无确认绝不下单**（`create_order()` 必须显式传 `confirm=True`）
> 2. **绝不代付** —— 只把官方链接原样交给你
> 3. **Token 绝不进仓库**

## 示例 5 · 一个必须诚实回答的问题

**用户**：帮我用券，能省更多吧？

**Agent**：能，但有一个例外必须跟你说清楚 ——

> 券和门店现价**可以叠加**（已实测）。
> **但同一款如果你点了多份，这张券我用不了。**
> 因为挂上券之后，接口会把这一款的份数**吃成 1** —— 你想买 3 杯，只给你 1 杯。
> **所以这种情况我宁可不挂券，也不能少给你。**

> **⚠️ 关键**：**知道边界在哪，就说边界在哪。** 该说不行的，不说"应该可以"。
