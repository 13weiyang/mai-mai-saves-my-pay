# 麦门搭子（暂名）· 说一句，麦麦就到

> 一个跑在电脑上的麦当劳点餐 Agent：**你说想吃什么，它替你点好。**

**你不用碰手机，也不用开口。**

办公室，下午。电脑开着，手机静音躺在一边。
想吃了，跟它说一句：

> 「来份麦辣鸡腿堡套餐」

它把剩下的都做了 —— **定门店、调菜单、领券、算价、下单**。
付款在麦当劳官方渠道完成，**我们不经手钱**。

**i 人的福音。**

---

## 它是什么

一个基于**麦当劳官方 MCP** 的点餐 Agent。

餐品、价格、优惠券、活动**全部实时来自官方接口**，不是本地写死的数据。

两种用法：

| 形态 | 是什么 | 适合谁 |
|---|---|---|
| **命令行** · `mai_mai.py` | 一行命令，把一单点完 | 想在终端里搞定的人 |
| **演示页** · `演示.html` | 单文件网页，全菜单带图摊开，点着选 | 想看着图挑的人 |

---

## 它能干什么

| 能力 | 说明 |
|---|---|
| 🏪 **找门店** | 给「城市 + 片区名」，按距离列出最近几家，带**店名 / 地址 / 距离** |
| 📖 **看菜单** | 按分类列出这家店的全部餐品，带**麦当劳官方产品图** |
| 🍔 **点名点单** | 说「巨无霸，冰美式中杯」就行 —— 口语和菜单名对不上时，它自己找得着 |
| 🎫 **自动领券** | **替你领**，不是提醒你去领：先把能领的券全领了，再把这一单能用的挂上 |
| 🧮 **官方算价** | 原价 / 省下 / 实付，**一律以官方算价结果为准** |
| 🛒 **下单** | 二次确认后创建订单，把**官方支付链接**交给你 —— **不代付** |
| 🛵 **外送** | 先确认收货地址，再查可配送门店；费用拆成**商品 / 配送费 / 打包费**报给你 |
| ↩️ **可取消** | 点错了能撤 |

| 🧭 **分类导航** | 左侧一列品类，点一下直接跳；滚动时自动高亮当前类；已点的品类带角标 |
| 👛 **随身钱包** | 跟着走的小钱包，实时显示金额，超预算会晃 |
| ✋ **已点入口** | 导航条最前面固定一个「已点 N 件」，一点直接看账单 |
| 🥡 **套餐自选** | 「随心拼 / 随心选」真能选：一轮一轮选够官方要求的件数，换贵的当场加钱 |
| 🧸 **儿童餐置顶** | 选「亲子餐 / 成人+亲子」→ 儿童餐与亲子套餐自动置顶成一组，**让孩子先选** |
| 📊 **实时算账** | 边点边算：原价 / 省多少 / 实付 |

## 怎么用

### 1. 申请麦当劳 MCP Token

1. 打开 <https://open.mcd.cn/mcp>
2. 右上角【登录】→ 手机号验证登录
3. 点【控制台】→【激活】→ 同意协议 → 复制 Token

### 2. 配置 Token

```bash
# 方式一：环境变量（推荐）
export MCD_MCP_TOKEN="你的Token"

# 方式二：放到项目上一级的 mcd-token.txt
echo "你的Token" > ../mcd-token.txt
```

### 3. 接入 MCP（在 WorkBuddy / Cursor / Trae 等客户端里）

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_TOKEN"
      }
    }
  }
}
```

> ⚠️ 把 `YOUR_MCP_TOKEN` 换成你的真实 Token。**真实 Token 不要提交到仓库。**

### 4. 命令行跑起来

```bash
# 先看看这家店有什么（不知道吃啥时用这个，带官方产品图链接）
python mai_mai.py --store 1950751 --show

# 主路：说要什么（不用报预算）
python mai_mai.py --store 1950751 --items "巨无霸,冰美式中杯"

# 算完直接下单（会有二次确认，确认后才真创建订单）
python mai_mai.py --store 1950751 --items "巨无霸" --order

# 外送（会先让你确认收货地址）
python mai_mai.py --city 北京 --keyword 嘉秀 --items "巨无霸" --order --delivery

# 不知道门店编码时：按「城市 + 片区」搜，列出最近的几家
python mai_mai.py --city 北京 --keyword 嘉秀
```

`--takeway` 选堂食 / 外带；`--remind "不要酸瓜"` 填备注（≤50 字）。

### 5. 看可视化演示

双击打开 `演示.html`（数据已内嵌，不需要起服务器）。
三家门店可切换，每道菜带**官方产品图**，预算是实时算的，算完可以**直接下单**（弹层二次确认）。

**无第三方依赖，只用 Python 标准库。**

## 几个需要知道的边界

| | |
|---|---|
| **门店距离是「离你给的地名」** | 接口不认经纬度，只认「城市 + 片区名」。所以关键词要填你**所在的片区**（如「嘉秀」「果园」），不然"离你最近"不成立。 |
| **菜单上的"现价"别信** | 约 45% 的"多件套"标着现价，接口实付却是原价。**算价一律以官方算价结果为准。** |
| **优惠来自哪里** | 门店现价折扣 + 券。券是**商品级指定特价**，一个商品挂一张。 |
| **份数 > 1 的商品不自动挂券** | 实测：挂券会把该商品的份数吃成 1（点 3 杯只给 1 杯）。所以**宁可不挂，不少给**。 |
| **外送费用要拆开看** | 外送的"原价"含配送费 + 打包费。别把三项加起来当商品价报。 |
| **菜单分时段** | 早餐时段查不到汉堡和儿童餐 —— 是时段限制，不是下架。 |
| **下单给的是支付链接** | 我们不代付，也不碰钱。付款这一步只在麦当劳自己的渠道完成。 |
